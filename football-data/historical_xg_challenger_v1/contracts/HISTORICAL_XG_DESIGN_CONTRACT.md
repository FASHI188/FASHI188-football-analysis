## Candidate responsibility

The challenger is a residual adapter over the frozen V1 pre-match means. It may use only xG/xGA released from earlier completed historical matches.

For each team, maintain separate home/away attack and defence residual states plus a strongly-shrunk pooled team prior.

For a completed match, after release only:

- attack residual = `log((xG_for + 0.25) / (V1_pre_match_mu_for + 0.25))`;
- defence-strength residual = `-log((xG_against + 0.25) / (V1_pre_match_mu_against + 0.25))`;
- residual is clipped to `[-0.75, +0.75]` before state update.

V1 pre-match expectation supplies opponent-strength correction mechanically; raw xG totals are never treated as opponent-neutral strength.

At prediction time, if all four relevant home/away attack/defence components have sufficient effective evidence:

- `delta_log_mu_home = beta * (home_attack - away_defence)`;
- `delta_log_mu_away = beta * (away_attack - home_defence)`;
- corrected means are `V1_mu * exp(delta_log_mu)` clipped only by the frozen V1 min/max rate;
- the score matrix and 1X2 are generated by frozen V1 `score_matrix` and `one_x_two`.

If reliable dynamic evidence is insufficient, both means/probabilities/score matrix must be byte-equivalent to the frozen V1 prediction payload fields being compared.

## State constraints

- Home and away venue states are distinct.
- Pooled team state is only a shrunk prior, never a second venue multiplier.
- Time decay is exponential and uses the frozen candidate half-life.
- Cross-season shrink is applied once per season transition snapshot and must not compound merely because a fixture is queried repeatedly.
- New/promoted/low-sample teams shrink to pooled zero residual, which means exact V1 fallback until evidence is sufficient.
- Defence state sign: larger positive value means stronger defence and must lower opponent `mu`.

## Strict historical PIT

- Source `date` defines the deterministic source-clock kickoff ordering.
- Result and xG release time is kickoff + 3 hours.
- Target fixture goals, xG, shots, shots-on-target or any other target post-match field cannot be read before its prediction is frozen.
- All fixtures with identical source kickoff timestamp are predicted before any update from that batch.
- Random splits are forbidden.
- Duplicate fixture IDs, same-team duplicate appearance in one kickoff batch, future release, identity mutation and invalid labels fail closed.

## Explicit exclusions

No odds, market data, Dixon–Coles, Mar-Co, draw multiplier, other joint-score correction, player/lineup/coach/Translator/tactics, fixture-specific or league-specific result patch, target-match post-view statistic, Provider or Secret.

All outputs are `HISTORICAL_PIT/OOS`, research-only, `formal_weight=0`, and never prospective or automatically enabled.
