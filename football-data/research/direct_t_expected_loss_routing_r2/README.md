# Direct-T Expected-Loss Routing R2

## Question

PR #179 already used a fixed Ridge expected-loss selector, but the selector saw only 39 expert-probability geometry features. It failed to learn a material fraction of the ~0.0352 row-oracle LogLoss gap.

R2 is a **post-view mechanism diagnostic** asking a narrower question:

> Is the missing routing information present in the already-existing pre-match state, or is the failure mostly due to the selector algorithm?

## Fixed diagnostic design

The expert family is unchanged:

- `common_baseline`: 47 core pre-match historical features;
- `R42F`: core + 18 frozen HT/FT response features;
- `R42J`: core + 18 frozen all-history pair-recovery features.

The selector shell is intentionally fixed and simple: `StandardScaler + Ridge(alpha=10.0)`. No grid, no threshold search, no competition identity, no realized T, no result-derived input.

Four diagnostic families are compared on the exact same already-VIEWED 1,584-row cohort:

1. `r1_absolute_geometry39` — exact R1 target style and 39 probability-geometry features;
2. `relative_geometry39` — predict each challenger expert's LogLoss difference vs common baseline;
3. `relative_geometry_core86` — add the 47 core pre-match state variables;
4. `relative_geometry_all122` — also add the frozen R42F/R42J expert input-state blocks.

The selector is fit only on policy rows generated by experts fit on chronological train rows. Target experts are fit on train+policy and evaluated on the exact previously VIEWED 1,584 rows.

## Interpretation boundary

This experiment is not independent confirmation. The 1,584 target labels were already viewed in PR #179/#202, and the idea is motivated by those results. Therefore:

- scientific PASS claim: forbidden;
- confirmation PASS claim: forbidden;
- formal promotion: forbidden;
- `formal_weight=0`;
- B01–B04 are not reclassified as blind/confirmatory;
- B05–B07 labels are not opened;
- any positive signal only justifies considering a separately frozen future OOS contract.

A descriptive development signal is recorded only when the primary 122-feature family gains at least 0.005 LogLoss vs common baseline, paired-bootstrap p95 is below zero, Brier/RPS are non-worse, and at least two experts are selected. That flag is explicitly **not** a scientific PASS.
