# Betfair public sample audit R1

This audit transiently reads 18 publicly accessible Betfair MATCH_ODDS stream files from a commit-pinned external GitHub repository. The source repository does not provide an explicit reusable data license, so raw files are never committed, persisted, redistributed or uploaded as artifacts. Only derived identity, cutoff-coverage and non-performance summaries are retained.

Settlement labels are counted only to determine whether a later preregistered pilot could be constructed. They are not used to select a threshold, fit a model or claim predictive performance.
