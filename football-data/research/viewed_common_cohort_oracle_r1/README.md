# VIEWED Common-Cohort Oracle R1

This is a retrospective forensic diagnostic over already-viewed historical data. It is not a new model family, not a protected confirmation sample, and not a formal promotion path.

## Question

On the same deterministic 1,000-match common cohort, do the frozen historical signals make different errors often enough to leave meaningful ex-post complementarity?

## Included frozen signals

- retrospective de-vigged market H/D/A consensus;
- R42D counterfactual standings H/D/A challenger;
- R40F rolling centrality structural signal;
- R42F Direct-T baseline/challenger;
- R42J Direct-T baseline/challenger.

R42F and R42J remain Direct-T signals. They are not converted into Draw probabilities in this audit.

## Hard boundaries

- existing viewed historical data only;
- deterministic identity-hash common cohort; labels do not select identities;
- no new collection, Provider, paid API, R44 forward capture, or new blind/holdout access;
- protected fixed100/fixed200 consumption = 0;
- no fusion selector, threshold tuning, manual Draw bonus, or manual total adjustment;
- `formal_weight=0`;
- no formal model/data/config/CURRENT/main mutation;
- PR #176 is untouched.

## Interpretation

A low ex-post oracle gap is evidence that these frozen signals contain little usable complementarity on identical matches.

A high ex-post oracle gap is only evidence that their errors differ after the fact. It does not show that a pre-match selector can identify which signal to trust. Any learnability test must be a separate preregistered time-ordered cross-fitted experiment and cannot be trained opportunistically on this diagnostic cohort.
