# Betfair public inventory audit R1

This audit transiently checks the complete historical-data directory of a commit-pinned public repository to determine whether its football MATCH_ODDS files contain enough timestamped pre-match LTP history for a future draw-trajectory study.

The external repository has no explicit reusable data license. Raw files are never committed, persisted or uploaded. The retained artifact contains only aggregate coverage, outcome counts used for sample-readiness gates, and failure receipts. No model is fitted and no predictive-performance result is produced.
