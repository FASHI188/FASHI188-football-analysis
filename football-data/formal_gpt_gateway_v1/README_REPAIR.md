# Target identity repair invariant

This integration-only repair does not change Football3 model parameters, Fusion V2 weights, Frozen V1, Historical XG Challenger, formal CURRENT, or production pointers.

For 2026/27 targets it resolves the request identity through the frozen current-season identity registry and selects a historical strength-state id only when exactly one explicit alias already has state evidence. Registered clubs with no state remain cold-started under their own canonical id. Exact-cutoff technical replay is permitted only when the durable state bundle validates and is already sealed at exactly the requested cutoff; that path performs no source acquisition.
