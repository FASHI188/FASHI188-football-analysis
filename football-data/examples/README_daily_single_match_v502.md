# Single-match input examples

- `daily_single_match_v502_live_template.json` is a fill-in template for a verified future match. It performs no lookup; all identity and freshness fields must be supplied from evidence frozen before kickoff.
- `daily_single_match_v502_offline_demo.json` is a deterministic CI scenario. It is not a verified fixture and must produce a formal abstention.

Never place the target result, final score, API keys, tokens, or postmatch fields in either input.
