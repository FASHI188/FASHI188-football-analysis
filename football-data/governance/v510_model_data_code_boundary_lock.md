# V5.1 模型、数据与代码边界锁定说明

> 状态：研究治理锁定说明  
> 日期：2026-08-05  
> 适用仓库：`FASHI188/FASHI188-football-analysis`  
> 权威边界：本文件不得修改或替代唯一 `CURRENT_唯一正式规则`。凡与唯一CURRENT冲突，以唯一CURRENT为准。

## 1. 唯一正式方向

唯一正式规则为：

`足球项目_CURRENT_唯一正式规则_V5.1.0_赛前联网信息强制入模与统一比分矩阵版.docx`

正式单场目标链固定为：

1. 比赛身份、90分钟口径和冻结时点核验；
2. 同步市场与赛前联网信息取得可核验证据；
3. 去水市场作为基础锚；
4. 冻结联网信息通过已验证残差模型修正市场；
5. 直接总进球轨预测 `P(T=0..6,7+)`；
6. 条件净胜球轨预测 `P(D|T,X)`；
7. 合成并审计唯一联合比分矩阵；
8. 从同一矩阵汇总胜平负、总进球和比分。

任何研究轨在没有显式晋级回执和CURRENT升级前，均不得进入上述正式链。

## 2. 五类资产的固定定义

### 2.1 旧正式模型

“旧正式模型”包括：

- R34历史进球时间＋比分状态路线；
- V5.1.0之前的旧概率中心、旧权重、旧参数和旧融合结果；
- 由旧模型生成的方向、概率和比分矩阵；
- 任何已被跨季或严格样本外否决的旧预测主链。

固定状态：`STOP / formal_weight=0 / execution_right=0`。

### 2.2 历史数据

“历史数据”指既有比赛身份、日期、90分钟赛果、比分、可用赛前字段和市场参考字段。

历史数据不是旧模型。只要满足身份、时序和无泄漏要求，可以继续用于新研究模型训练、政策期选模和滚动回测。

缺少原始报价时间戳的历史收盘赔率只能标记为“回顾性市场参考”，不得冒充正式赛前快照。

### 2.3 通用研究代码

“通用研究代码”包括：

- 数据读取与清洗；
- 比赛身份映射；
- 时间顺序切分；
- 同日先预测后更新；
- 指标、Bootstrap和审计器；
- 只使用比赛前已完成历史数据构造的通用特征；
- 哈希、冻结、账本和Artifact证据工具。

通用代码可以复用。复用通用代码不等于复活旧模型。

### 2.4 V5.1历史研究挑战轨

R19、R20及后续明确标记为V5.1研究挑战的模块，属于“当前研究轨”，不是旧正式模型，也不是正式新模型。

它们必须始终满足：

- `formal_weight=0`；
- 只在研究分支运行；
- 测试集不得参与候选选择；
- 不得生成当前比赛正式概率；
- 不得进入正式联合矩阵；
- 不得因历史回放改善而自动晋级。

### 2.5 V5.1正式新模型

“正式新模型”只指完整实现并通过晋级的V5.1正式单场链：同步市场＋联网冻结信息＋直接总进球＋条件净胜球＋统一比分矩阵。

当前状态：尚未正式实现、验收或晋级。

## 3. 旧模型的允许与禁止用途

### 允许

- 保存代码和历史回执用于审计；
- 作为只读基准参加横向比较；
- 分析失败原因；
- 验证新研究轨是否真正优于旧基准。

### 禁止

- 旧概率作为新模型输入；
- 旧权重、旧参数或旧比分矩阵参与融合；
- 继续调参、续训或包装成新模型；
- 用旧模型替代联网信息残差模型；
- 用旧模型输出当前比赛方向、总进球、比分或EV；
- 因旧模型在某一历史样本表现较好而恢复执行权。

结论：旧模型可以被比较，但不能被使用。

## 4. 历史数据和既有代码的固定用途

历史26,873场数据继续作为研究开发样本，不等待未来比赛才能开始训练。

固定历史研发方式：

1. 所有特征只能来自该比赛之前已完成的比赛和当时可见字段；
2. 同一天比赛必须全部先预测，再统一更新；
3. 候选选择只能发生在训练期或政策期；
4. 固定1000场标签盲选样本用于快速比较；
5. 全部15,639场滚动测试用于阶段审计；
6. 已反复查看的历史结果只能称为 `VIEWED_HISTORICAL_DEVELOPMENT`，不能称为独立确认；
7. 新前向比赛用于最终确认和严格PIT校准，不是历史训练启动门。

## 5. R19与R20的唯一正确身份

### R19

- 名称：历史直接1X2研究挑战轨；
- 状态：历史回放已完成；
- 结果：总体Log Loss、Brier、RPS和Top-1相对历史基线改善；
- 缺陷：平局Top-1召回仍接近零，平局问题未解决；
- 正式权重：0；
- 裁决：保留为研究信号和比较基准，不进入正式预测。

### R20

- 名称：分层平局优先1X2研究挑战轨；
- 方法：先学习 `P(平局|X)`，再学习 `P(主胜|非平局,X)`，自然合成三项概率；
- 状态：研究工作流已提交，尚未形成有效结果；
- 正式权重：0；
- 裁决：继续作为当前研究实验运行；不得称为旧模型复活，也不得称为正式新模型。

任何把R19/R20称为“旧正式模型继续使用”或“正式模型已经完成”的表述，均为错误。

## 6. 前向链R14—R18的固定身份

R14—R18是严格PIT数据、冻结、追加、赛前回执、候选队列和赛后结算基础设施。

固定边界：

- 真实捕获样本当前为0时，不得声称已训练联网模型；
- 前向20场不阻塞历史研究；
- 前向样本不得被CI样例、回顾性赔率或无原始时间戳数据替代；
- 前向链通过只说明证据链可运行，不说明预测有效；
- 前向比赛主要承担独立确认、漂移检查和联网残差校准证据。

## 7. 研究晋级硬门

研究轨只有同时满足以下条件，才允许提出晋级：

1. 严格时间顺序样本外或前向验证；
2. Log Loss、Brier、RPS不劣于市场基准，并达到预注册改善门；
3. 校准斜率、截距和分箱残差通过；
4. 平局概率质量和Top-1行为不存在结构性失效；
5. 多滚动窗口、赛事域和赛季稳定；
6. 若进入正式比分链，直接总进球、条件净胜球和统一矩阵均真实运行并通过审计；
7. 获得显式promotion receipt；
8. 正式语义变化写入新的唯一CURRENT文件。

缺少任一项，继续保持 `formal_weight=0`。

## 8. 当前单场正式输出边界

在V5.1正式新模型尚未晋级前：

- 同步可成交1X2可作为90分钟赛果基础锚；
- 联网信息可以被查证和结构化，但没有已验证残差算法时不得人工改概率；
- 直接总进球轨未真实运行时固定输出：`总进球分布不可用。`；
- 统一比分矩阵未真实运行或审计未通过时固定输出：`精确比分不可用。`；
- 没有实际赔率时不得计算EV。

## 9. 变更规则

本锁定说明后续不得靠聊天临时改写。

- 研究边界变化：必须修改本文件、提交Git commit并更新Airtable维护日志；
- 正式模型、权重、主链或输出语义变化：必须生成新的完整唯一CURRENT，完成唯一性替换和启动验收；
- 未完成上述步骤的口头表述没有长期执行权。

## 10. 最终一句话

**旧正式模型停止且不得参与新预测；历史数据和通用无泄漏代码继续用于V5.1新研究；R19/R20是权重0的当前研究挑战轨；只有完整V5.1联网统一矩阵链通过独立晋级后，才取得正式执行权。**
