# Acceptance target

A candidate HEAD is acceptable for GPT development completion only when the read-only workflow succeeds on the exact PR head, existing formal regressions pass, the new unit tests pass, the offline end-to-end report is generated, matrix and marginal probabilities conserve mass, A-H output is complete, provider requests and key access remain zero, and protected formal assets have zero diff.

This is not Codex acceptance and does not authorize merge.
